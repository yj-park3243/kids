기타

A. 색인 탭

  • 기간 4개가 스크롤 없이 한눈에. "목록 = 종이 한 장" 은유가 강함
  • 구현 쉬움 — 탭바 + 카드. 상태도 탭 하나
  • 장소·아이는 결국 빈칸/드롭다운이라 두 문법이 섞임
  • 탭이 5개를 넘으면 무너짐(나중에 '주말' 같은 게 늘면)

B. 포스트잇 보드

  • 가장 '같이크자'다움. 자주 쓰는 조건 4~5개면 딱 좋음
  • 이름표(아이) 처리가 자연스러움 — 모서리에 붙은 스티커
  • 세로 공간 90px 먹음. 목록이 그만큼 내려감
  • "오늘 + 이번 주말" 처럼 겹치는 조건의 규칙을 사용자가 알기 어려움 → 포스트잇은 프리셋으로만, 정밀 필터는 '더보기'
  • 구현 비용 중간 — 회전·테이프·체크 애니메이션

C. 빈칸 채우기

  • 한 줄 40px. 스크롤 없음. 현재 상태가 늘 문장으로 읽힘("오늘 · 어디든 · 두번")
  • 조건이 늘어도 빈칸 하나 추가 — 비용·입장 방식·시간대까지 확장 가능
  • 아이 1명이면 '누구' 빈칸을 빼면 끝(지금 요구와 정확히 맞음)
  • 칩보다 탭 1번 더 (빈칸 → 시트 → 선택). 눌러도 되는지 몰라볼 수 있어 연필 아이콘·점선 밑줄 필요
  • 구현 쉬움 — 한 줄 텍스트 + 바텀시트(이미 아이 선택 시트 있음)
추천: C(빈칸) 를 기본으로, B(포스트잇) 는 홈에.
모임 찾기의 필터는 매번 만지는 게 아니라 "지금 조건이 뭔지"가 늘 보이는 게 중요해서 C 가 맞습니다. 포스트잇은 목록 위에 올리면 공간을 먹지만, 홈 화면에 "오늘 놀이터 · 이번 주말 · 무료" 같은 바로가기 3장으로 붙이면 수첩 느낌도 살고 모임 찾기로 들어가는 문도 됩니다. 색인 탭(A)은 내 모임의 [예정 | 지난] 세그먼트에 쓰면 어울립니다 — 지금 회색 알약보다 수첩답습니다.
