# 09. UI 수첩안 — "우리 동네 육아 수첩"

2026-09-09 확정. 웹 프로토타입: `docs/ui_notebook_prototype.html` (브라우저로 열면 폰 프레임 6개가 보인다).
이 문서는 Flutter 앱 전 화면을 이 안으로 옮길 때의 **계약**이다. 토큰·공용 위젯은 이미 코드에 있다.

## 0. 왜 바꾸나

이전 UI가 어수선했던 원인은 기능이 아니라 장식이었다.

| 이전 | 문제 |
|---|---|
| 모든 화면 뒤 블러 블롭 4개 (`AccentBlobsBackground`) | 위에 놓인 모든 것이 흐려 보임 |
| 카드마다 유리 그림자 + 좌측 액센트 바 (`GlassCard`) | 전부 떠 있으니 아무것도 안 뜸 |
| 방 카드 하나에 그라데이션 3개 + 칩 5종 | 목록에서 필요한 건 "언제·어디·몇 개월"뿐 |
| primary 12단계 + 보조 5색 + 장소별 5색 | 색이 정보를 안 가짐. CTA가 안 보임 |
| 고운돋움(단일 굵기) + 도현 | 굵기 위계가 없어 크기로만 강조 → 글자가 커지고 산만 |

## 1. 원칙 (이것만 지키면 된다)

1. **배경은 종이 한 장.** `AppColors.paper` 단색. 블롭·그라데이션 없음. `Scaffold` 기본 배경이 이미 paper 다.
2. **떠 있는 건 화면에 하나.** 그림자는 `AppCard(hero: true)` 한 장에만(홈의 '다음 모임'). 나머지 카드는 1px 헤어라인.
3. **카드보다 목록.** 반복되는 항목은 카드가 아니라 **행 + 점선 괘선**(`DashedDivider`). 강조할 것 하나만 카드.
4. **색이 정보다.** 한 화면에 포인트 색은 한두 곳.
   - `hi`(형광펜 노랑) = 모집중 · 오늘 · 활성 탭 · D-day · 내가 만든 모임
   - `sky` = 아이·개월수 · `sage` = 쑥쑥 등급 · `berry` = 안읽음/알림 점
   - CTA·선택됨·내 말풍선 = `ink`(검정). 링크 = `link`(파랑)
   - 그 밖의 속성(승인 필요·마감·인원·준비물)은 `muted` 회색
5. **굵기로 말한다.** Plex 400/500/600/700. 위계를 크기로 내지 말 것.
6. **손글씨(개구체)는 숫자와 인사말에만.** 날짜·개월수·통계·D-day. **문장에 절대 쓰지 않는다.**
7. **한 항목에 pill 은 2개까지.** 3개째부터는 상세에서 보여준다.
8. 수첩 장치(형광펜·점선·테이프·도장)는 **"지금·여기·오늘"을 가리킬 때만.** 장식으로 늘어놓으면 스티커북이 된다.

## 4. 화면별 지침 (프로토타입 기준)

공통: 앱바 제목은 `screenTitle`, 좌우 여백 20, 섹션 제목은 `SectionHeader`. 카드 안에 카드 금지.

### 홈 (home_dashboard_screen)
- 앱바: 왼쪽 워드마크 `Text('같이크자', style: wordmark)`, 오른쪽 알림 아이콘(점 = berry).
- 인사말: 작은 "하율 부모님," (body2) + `greeting` 한 줄. 핵심 단어 하나만 `Highlight`. 예: "내일 성미산에서 / **만나요**", 예정 없음: "이번 주 / **놀러 갈까요?**".
- **다음 모임 카드** = 화면 유일한 `AppCard(hero: true)`, 위에 `MaskingTape`. 안: `Stamp('D-1')` + 요일·날짜, 제목 18/700, 시계·핀 아이콘 두 줄, 점선, 아바타 겹침 + "4/6명"(4는 hand), 오른쪽 고스트 '채팅' 버튼 + unread 배지.
- 빠른 진입 3칸: 모임 만들기 / 주변 모임 / 사진첩 — 흰 면 + line, 아이콘 + 라벨.
- 이번 주: 7칸 스트립. 요일(caption) / 날짜(handXl 22) / 점(모임 있는 날 ink). 오늘 숫자 뒤 `HighlightMark`.
- 자주 만난 친구: 가로 스크롤 아바타 + 이름 + "같이 4번".
- 함께한 기록: 3칸(handXl 숫자 + caption), 칸 사이 점선 세로선. 월간 달력·마일스톤·사진 스트립 섹션은 **삭제** — 홈은 다음 모임 하나에 집중.

### 모임 찾기 (home_screen, room_card)
- 앱바: '모임 찾기' + 모서리 이름표 스티커 `NameTag`("두번 33개월", 누르면 아이 선택 시트) + 노란 알약 "＋ 만들기".
- **필터는 칩이 아니라 포스트잇 보드**(2026-09-09 결정, `docs/ui_filter_notebook_prototype.html` B안): 한 줄 4칸 `PostIt` — 오늘 · 이번 주(노랑) · 놀이터(하늘) · `PostItSlot` "＋ 조건 더보기". 붙이면 회전 0·테이프·펜 ✓, 다시 누르면 뗌. 기간/장소는 독립 축. 더보기 시트는 "언제 놀까요? / 어디서 놀까요?" 손글씨 질문 + `_CheckRow` 체크 칸. 보드에 없는 조건이 켜지면 아래 "붙인 조건: 내일 · 키즈카페 · 모두 떼기" 한 줄.
- 옆으로 스크롤하는 칩 줄은 쓰지 않는다 — 앱의 관성이지 수첩 문법이 아니다.
- 아이 캡션 "두번(33개월)이 참여할 수 있는 모임만 보여요 · 전체 보기"(33은 hand). 아이 1명이면 선택 UI 없이 이 줄로만 풀고 되돌린다.
- 목록: `GroupLabel`("오늘 · 9월 12일 금요일" / "내일" / "다음 주") + 행. 행 = `DateBlock` | 제목(cardTitle) + 한 줄 메타("10:30 · 장소 · 동", 점 구분) + pill ≤2(sky 개월수, muted 승인필요/준비물) | 오른쪽 상태 pill(hi 모집중 / muted 마감·참여 중) + "3/5명" caption. 행 사이 `DashedDivider`.
- `RoomCard` 는 이 행으로 교체(그라데이션·태그 칩 제거). 다른 화면이 `RoomCardCompact` 를 쓰면 같은 규칙의 작은 행으로.

### 모임 상세 (room_detail_screen)
- 그라데이션 헤더 **제거.** 흰 종이 위에: pill 줄(hi 모집중 · muted 승인 필요 · sky 개월수) → 제목 `display` → 방장 행(아바타·닉네임·"🌿 어린나무 · 함께한 모임 8회") → 점선.
- 정보 목록(kv): 아이콘 22 | 라벨(caption) + 값(body1 500). 일시(날짜 숫자는 handLg) · 장소(+ "지도 보기" link) · 인원("2 / 4명", 2는 handLg) · 비용 · 준비물. 항목 사이 점선.
- 참여자: 가로 아바타 44 + 이름 + (방장은 hi 태그) + 빈 자리 점선 "+".
- 모임 소개 `paragraph`. 약속(취소 규정·후기 기한)은 `DashedBox`.
- 하단 고정 CTA: `PrimaryButton('참여 신청')` + 아래 12px 안내 "처음 참여할 땐 휴대폰 본인 인증을 한 번 해요". 참여 중이면 '채팅 열기' 고스트 + 필요 시 후기/출석.
- ⋮ 메뉴·나가기·취소·강퇴 등 **기존 기능과 Key(`btn-room-detail-join` 등)는 전부 유지.**

### 지도 (map_screen, widgets/pin_sheet.dart)
- 핀 시트는 `PinSheet`(`DraggableScrollableSheet`) — 세 단계: **미리보기 40%**(제목·메타·pill 2·CTA·"위로 끌어 올리면 더 볼 수 있어요") → **펼침 72%**(방장·소개·참여자 아바타·준비물/비용 `DashedBox`·'자세히 보기') → **95%까지 올리면 방 상세로** 이동. 아래로 끌면 닫힘, 핸들 탭으로 접기/펼치기.
- 핀 탭 시 카메라를 남쪽으로 살짝(화면 10%) 옮겨 핀이 시트에 가리지 않게. FAB은 시트 높이를 따라 올라간다.
- 펼침 내용은 시트가 미리보기보다 올라올 때 페이드인(미리보기 상태에서 탭바 밑으로 비치지 않게). 상세 데이터는 시트가 올라가기 시작할 때 `roomDetailProvider`로 미리 로드.
- 네이티브 마커는 위젯 트리에서 탭할 수 없어 UI 테스트는 `MapScreen.debugSelectFirstPin()`(테스트 빌드 한정)로 시트를 띄운다.

## 7. 적용 현황 (2026-09-09)

전 화면 적용 완료(에이전트 6개 + 리드). `flutter analyze` 0 error, 단위 테스트 17 통과(기존 `widget_test` Firebase 실패 1건은 무관).

**시뮬레이터 육안 검증 완료(iPhone 17 Pro, 9/9)**: `run_smoke.sh` 15단계 전부 통과 + `integration_test/ui_visual_tour_test.dart`(참여 → 방 상세 → 채팅 → 홈 다음 모임 카드 → 내 모임 → 만들기) 9장. 스크린샷은 `app/test_results/`. 검증 중 고친 것:
- `Highlight` 가 음수 margin 으로 assertion → `Positioned` 음수 오프셋으로 교체.
- 모임 찾기 필터 칩 행이 lazy `ListView` 라 스크롤 시 '전체' 칩이 트리에서 사라짐 → `SingleChildScrollView(Row)`.
- 마이 헤더 '편집' 버튼 4px 오버플로 → `GlassButton(compact: true)`; 고정 폭일 때 안쪽 여백 축소.
- `EmptyState` 버튼 글자가 검정 위 검정 → 흰색 명시.
- 이메일/소셜 로그인 응답에 `children` 이 없어 마이 '우리 아이'가 비어 보이던 기존 버그 → 로그인 후 프로필 재조회(`_hydrate`).
- 채팅방 제목이 목록 캐시 없을 때 '채팅' 폴백 → 방 상세 캐시 제목 사용.
- 시스템 권한 팝업(ATT·알림)이 스크린샷을 가려 `--dart-define=UI_TEST_SKIP_ATT=true` 로 테스트 빌드에서만 건너뜀.

알려진 소소한 것: 지도 필터 패널을 펼치면 오른쪽 '모임 N개'·새로고침·내 위치 버튼이 패널 위에 겹친다(기존과 동일한 배치). 만들기 폼의 '1/4' 가 앱바와 본문에 두 번 보인다(테스트 호환).

프로토타입과 다르게 간 곳 — 전부 데이터/테스트 제약이고 UI 구조는 동일:
- 홈 다음 모임 카드: `GET /rooms/my`가 `members`·`placeName`·`endTime`을 안 줘서 시작 시각만, 아바타는 방장 1명 + 빈 자리, 장소는 `regionDong`. 서버가 내려주면 그대로 채워진다.
- 모임 찾기: 검색 입력은 서버·provider에 검색이 없어 **넣지 않았다**(가짜 UI 금지). 메타 줄의 장소는 `placeName`이 목록 API에 없어 장소 유형으로 대체.
- 내 모임: '할 일'(후기 D-n·출석) 섹션과 '승인 대기' 행은 그 데이터를 주는 provider가 없어 생략. `getMyRooms`는 members 이너조인이라 대기 방이 목록에 안 온다.
- 방 상세: 방장 행의 "🌿 등급 · 함께한 모임 N회"는 `RoomHost` 모델에 필드가 없어 시군구로 대체. 참여자 제목은 테스트 호환으로 `참여자 (2/4)` 유지. 만들기 앱바 `모임 만들기 (1/4)`도 테스트 호환으로 유지(본문에 손글씨 스텝 별도).
- 마이: '차단한 유저'·'프로필 수정' 문구/메뉴는 스모크 테스트 호환으로 유지. 1:1 문의 답변 배지·사진첩 메뉴는 데이터/라우트가 없어 생략.
- 채팅: 입력바 ＋ 아이콘은 위치 전송 전용이라 위치 아이콘 유지. 앱바 인원수는 `roomDetailProvider` 캐시가 있을 때만.
- 통합 테스트: 목록 카드 타입이 `RoomCardCompact` → `RoomCard`로 바뀌어 6개 테스트의 finder를 갱신했다.
